# Gate 1 slice: QA scenarios (backlog T20)

How to use this list: the **automated** column names the headless test that already checks the scenario (run them from this folder, see `readme.md`); the **manual** column is what only a person can judge. Everything here runs against the real level and the real `GameState`. The two full-slice runs take a few minutes each now the lines are recorded (the game runs at 8x):

```bash
godot --headless --path . --script res://tools/test_slice_playthrough.gd            # S01, the whole win
godot --headless --path . --script res://tools/test_slice_playthrough.gd -- fail    # S02, the failure and the restart
bash tools/run_all_tests.sh                                                         # every test, timed, with a summary table (QA-09)
```

Phase order the machine must follow, one step at a time: ARRIVAL_AND_COAL, SHELTER_AND_GATE (BOILER_FED), BEACON_DIAGNOSIS (DANIEL_IN_BASEMENT), BOARDING (BURNER_BRIEFING), OUTBOUND (BOAT_CAST_OFF), SALTGATE (SALTGATE_REACHED), RETURN (RETURN_DEPARTED), FINAL_REPAIR (RETURN_ARRIVED), RESOLUTION (SHIP_WIN or SHIP_FAIL). No fail state exists before RETURN_DEPARTED; the outcome resolves exactly once per attempt.

Updated 3 Nov 2026 by the Playtest QA agent (QA-02) for the day's changes: Daniel's per-visit lines, Ted's firebox and poster gates, the recorded voices and their placement, the music, the ducking, the win text and the last goal. The 2 Nov version is in `GERFramework/reports/backups/QA_SCENARIOS_v1_2026-11-02.md`. The difficulty row was a second S18; it is now S21 (the goal tracker keeps S18).
